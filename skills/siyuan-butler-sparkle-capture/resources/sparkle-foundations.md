# Sparkle 基础

## 1. Sparkle 不是什么

- 不是完整笔记
- 不是摘要
- 不是缩短版正式条目

## 2. Sparkle 是什么

- Sparkle 是最小可回忆单元
- Sparkle 是一个“重返入口”
- 成功标准不是完整，而是能不能把未来的自己带回去

## 3. 最小成立结构

- `source`：从哪里亮起来
- `glow`：这里最值得保住的方向感

可选增强：

- `trace`
- `pull`

## 4. 三条豁免权

- 不要求完整句子
- 不要求当场解释清楚
- 不要求立刻形成双链

没有这三条，Sparkle 很容易退化成“短一点的正式笔记”。

## 5. 两类 Sparkle

### 5.1 感受型

- 目标：保住气味
- 常见场景：音乐、摄影、情绪、审美、生活感受
- 适合材料：意象词、关系词、类比、时间点、局部观察

### 5.2 认知型

- 目标：保住判断
- 常见场景：博客启发、产品灵感、方法论、技术判断、科研结论
- 适合材料：触发点、自己的改写理解、待展开方向

## 6. daily note 在这里的角色

daily note 不是 Sparkle 的第一入口，而是汇流层。Capture 的目标不是把内容写成完整日记，而是先把火花保存为未来可再碰的入口。
