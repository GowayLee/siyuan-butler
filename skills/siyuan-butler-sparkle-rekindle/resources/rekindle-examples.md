# Rekindle 例子

## 1. 适合复燃的例子

原 Sparkle：

- `source`: 某篇关于 declarative system 的博客
- `glow`: 真正减少的是长期迁移成本，不只是复现

复燃判断：

- 现在已经能说清楚为什么这个判断重要
- 可以形成一条正式工作记录

提案方向：

- `entry_title`: 关于 declarative system 价值的一个工作判断
- `entry_body`: 围绕“迁移成本”展开，而不是重复博客摘要

## 2. 暂不适合复燃的例子

原 Sparkle：

- `source`: Debussy《Nuages》1:43
- `glow`: 云层不是飘，是悬着不落

如果当前还只是觉得这个意象很好，但没有进一步长出稳定判断或要写进今天时间线的意义，那么更适合继续停留为 Sparkle，而不是硬写成正文。

## 3. brief 与 full 的区别

### 3.1 `brief`

- 适合已经有稳定判断，但只需要一段短记录时
- 重点是把判断落入时间线

### 3.2 `full`

- 适合已经形成较完整条目结构时
- 重点是把背景、判断、理由说清楚

### 3.3 `postpone`

- 适合当前仍需继续发酵时
- 重点是保留提案，不强制写入
