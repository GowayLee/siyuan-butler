# Rekindle 成熟度判断

## 1. 复燃不是扩写

复燃的核心不是“能不能写长”，而是“现在值不值得写进时间线”。

## 2. 三个核心判断

### 2.1 有没有稳定中心

- 是否已经形成一个稳定判断
- 或者已经形成一个稳定感受切面

### 2.2 有没有足够上下文

- 当前上下文是否已能支撑正式条目
- 写进去后是否仍然是可理解的时间痕迹

### 2.3 为什么是现在

- 现在写进去的意义是什么
- 如果再放一放，会不会更好

## 3. 三档成熟度

### 3.1 `borderline`

- 刚开始成形
- 已有方向，但还不稳
- 更适合继续讨论，或停在提案层

### 3.2 `ready`

- 中心判断已经成立
- 可以形成一条清晰正式记录
- 写进去后能成为有价值的时间痕迹

### 3.3 `strong`

- 判断或感受很稳定
- 正文提案已经清楚
- 写入理由和可能影响都容易解释

## 4. 什么时候应 `postpone`

- 仍只有火花，没有稳定条目中心
- 写出来会显得空、泛、像硬凑总结
- 用户只是试探成熟度，不是现在就想写

`postpone` 不是失败，而是承认这条 Sparkle 现在更适合继续活着，而不是被提前定型。
