# Sparkle 基础

## 1. Rekindle 为什么先要尊重 Sparkle

复燃不是把一条短句机械拉长，而是把一条仍然保有火花来源的 Sparkle，推进成值得进入时间线的正式条目提案。

因此，rekindle 的第一步不是扩写，而是先保住原 Sparkle 的火花来源。

## 2. Sparkle 的稳定定义

- Sparkle 不是完整笔记
- Sparkle 是最小可回忆单元
- Sparkle 的价值在于让未来的自己重新回到那个判断、感受或联想

## 3. Rekindle 不能抹掉的东西

- `source`
- `glow`
- 必要时的 `trace`
- 必要时的 `pull`

如果 rekindle 一开始就把原对象抹平成普通摘要，通常意味着已经失去复燃的语义起点。

## 4. daily note 的角色

daily note 的正文是汇流后的正式痕迹，不是 Sparkle 的第一入口。只有当内容已经成熟到值得进入时间线时，rekindle 才应该把它推进到正文提案。
